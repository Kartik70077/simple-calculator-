# 🧮 Simple Calculator

A simple, responsive calculator built using **HTML, CSS, and JavaScript**. This project is designed for beginners who want to learn the fundamentals of web development by building a practical application.

## ✨ Features

- **Basic arithmetic:** Addition, subtraction, multiplication, and division.
- **Decimal support:** Perform calculations with decimal numbers.
- **Clear button:** Reset the calculator at any time.
- **Backspace:** Remove the last entered digit.
- **Keyboard support:** Use your keyboard to enter numbers and operators.
- **Responsive design:** Works on desktop and mobile screens.
- **Error handling:** Displays an error when dividing by zero.
- **Clean interface:** Simple layout with interactive buttons.

## 🛠️ Technologies Used

- **HTML5** — Structures the calculator interface.
- **CSS3** — Styles the calculator and makes the layout responsive.
- **JavaScript** — Handles button clicks, calculations, and keyboard input.

## 🚀 Getting Started

### Option 1: Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start calculating!

No additional software installation or build tools are required.

### Option 2: Clone Using Git

```bash
git clone https://github.com/Kartik70077/simple-calculator-.git
cd simple-calculator-
```

Then open `index.html` in your browser.

## 🧑‍💻 How to Use

1. Click the number buttons to enter a number.
2. Select an arithmetic operator: `+`, `−`, `×`, or `÷`.
3. Enter the second number.
4. Press `=` to display the result.
5. Use `C` to clear the calculator.
6. Use `⌫` to delete the last digit.

### Keyboard Shortcuts

| Key | Action |
|---|---|
| `0–9` | Enter a number |
| `+` | Addition |
| `-` | Subtraction |
| `*` | Multiplication |
| `/` | Division |
| `.` | Decimal point |
| `Enter` or `=` | Calculate the result |
| `Backspace` | Delete the last digit |
| `Escape` or `Delete` | Clear the calculator |

## 🧮 Example Calculations

| Calculation | Result |
|---|---:|
| `5 + 3` | `8` |
| `10 - 4` | `6` |
| `6 * 7` | `42` |
| `20 / 5` | `4` |
| `7 / 0` | `Error` |

**Note:** This calculator evaluates operations sequentially from left to right. It does not follow standard mathematical operator precedence. For example, `2 + 3 × 4` produces `20` rather than `14`.
